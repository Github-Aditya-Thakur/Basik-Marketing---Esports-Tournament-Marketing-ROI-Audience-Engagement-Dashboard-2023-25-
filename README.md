# Basik Marketing — Esports Marketing Dashboard (Power BI)

## Problem & Context
**Basik Marketing** needed a clear, executive‑level view of esports campaign performance. The data was spread across platforms, channels, events, and regions, making it difficult to identify what was working, where engagement was strongest, and which channels delivered the best ROI.

## Data Used
This project uses **synthetic (simulated) data** created for portfolio and demonstration purposes. It does **not** represent real client or platform data.

## How We Solved It
We built a **multi‑page Power BI dashboard** that:
- Consolidates all marketing metrics into one report
- Highlights **key KPIs** for leadership
- Breaks down performance by **platform**, **channel**, **event**, and **region**
- Enables **fast filtering** using synced slicers across pages
- Uses **trend analysis** to show engagement and conversion changes over time

## Pages Included
1. **Executive Overview**  
   High‑level KPIs (Spend, Conversions, Impressions, Clicks, CTR, Signups) and event‑based conversion trends.

2. **Channel Performance**  
   Spend vs. results by channel, conversions by channel, and platform‑based impressions/clicks.

3. **Engagement & Retention**  
   Engagement trend, engagement by region, and average watch time by game.

4. **Campaign Efficiency & ROI**  
   Relationship between spend and conversions, and top‑performing channels.

5. **Final Insights**  
   Summary visuals with platform‑level conversion comparison.

## Key Features
- **Executive KPI cards** with consistent formatting  
- **Top‑N filtering** for focus  
- **Synced slicers** across all pages  
- **Clean layout** aligned to a grid  
- **Sorted visuals** for fast decision‑making

## Slicers (Synced Across Pages)
- **Date**
- **Region**
- **Platform**
- **Channel**

## Example Insights
- A few **top channels drive most conversions**
- Engagement peaks around specific esports events
- Certain platforms consistently outperform others
- Spend vs conversions reveals ROI differences across channels
